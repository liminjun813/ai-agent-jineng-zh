# 案例：营销增长 — 北极星指标与营销创意

## 背景

上市策略确定后，需要具体的营销增长方案。

## 使用pm-marketing-growth技能

### 1. north-star-metric — 北极星指标
```
请为「智选AI」定义北极星指标：
- 产品：AI电商推荐平台
- 用户：三四线城市宝妈
- 阶段：MVP上线后
```

输出：
```
北极星指标：每周通过AI推荐完成交易的用户数

支持指标：
- 输入指标1：AI推荐被点击率（CTR）
- 输入指标2：推荐商品下单转化率
- 输入指标3：用户周活跃天数
- 输入指标4：推荐节省金额（用户感知价值）
```

### 2. marketing-ideas — 营销创意
```
请为「智选AI」生成5个低成本营销创意：
- 预算：每个方案不超过5000元
- 渠道：微信、抖音、小红书为主
- 目标：三四线城市宝妈
```

示例输出：
```
创意1：「省钱挑战」社群活动
- 方法：在宝妈群发起"一个月用AI省钱挑战"
- 渠道：微信社群 + 抖音短视频
- 成本：2000元（奖品+素材）
- 预期：单次活动获取2000用户
```

## 关键要点

- 北极星指标让团队**聚焦同一个目标**
- 营销创意确保获客**低成本、可复制**
