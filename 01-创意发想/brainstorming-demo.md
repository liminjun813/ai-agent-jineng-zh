# 案例：头脑风暴 — 为「智选AI」寻找切入点

## 背景

我们有一个AI电商推荐平台的概念，但需要确定：
1. 目标用户是谁？
2. 核心差异点是什么？
3. 如何获客？

## 使用brainstorming技能

打开Hermes Agent，加载 `superpowers:brainstorming` 技能，输入以下prompt：

```
我正在创业做一个AI驱动的电商推荐平台，主要面向中国三四线城市消费者。
请用brainstorming技能帮我分析：
1. 目标用户画像（至少3个细分群体）
2. 核心差异点（与淘宝/拼多多的区别）
3. 获客渠道建议
4. 商业模式建议
请用结构化方式呈现分析结果。
```

## 预期输出

技能会引导AI Agent按照brainstorming框架输出：
- **多视角分析**：产品经理视角、用户视角、投资人视角
- **创意矩阵**：每个维度的3-5个备选方案
- **可行性评估**：每个方案的可行性评分

## 关键要点

- brainstorming不是漫无目的的头脑风暴，而是**有框架的创意生成**
- 技能确保AI不会只给"通用答案"，而是针对具体场景深入分析
- 适用于：**新产品定位、功能设计、市场进入策略**
