# 案例：PM工具包 — NDA与隐私政策

## 背景

与供应商（AI推荐算法合作方）合作前，需要签署NDA。产品上线需要隐私政策。

## 使用pm-toolkit技能

### 1. draft-nda — 起草NDA
```
请起草一份NDA：
- 甲方：智选AI科技有限公司
- 乙方：XX AI技术公司
- 保密信息：推荐算法代码、用户数据、商业计划
- 期限：2年
- 适用法律：中华人民共和国
- 管辖法院：甲方所在地法院
```

### 2. privacy-policy — 隐私政策
```
请为「智选AI」电商APP起草隐私政策：
- 数据类型：用户基本信息、购物记录、位置信息
- 数据用途：个性化推荐、订单处理、安全风控
- 数据存储：中国大陆境内服务器
- 数据共享：与物流服务商共享必要信息
- 适用法律：中国《个人信息保护法》《数据安全法》
- 用户权利：查阅、更正、删除、撤回同意
```

## 关键要点

- pm-toolkit处理的是**法律合规类文档**
- NDA保护合作中的知识产权
- 隐私政策是产品**上线的合规要求**
- ⚠️ 建议：重要法律文件应由律师最终审核
