# AI Agent 技能选择决策树

> 遇到问题时，不知道用哪个技能？跟着这个决策树一步步选。

---

## 🌳 一级决策：你现在在做什么？

```
开始
  │
  ├─ 我在想点子/找方向 ──→ 用 brainstorming
  │
  ├─ 我在规划怎么做 ──→ 用 writing-plans
  │
  ├─ 我在做市场调研 ──→ 用 pm-market-research
  │
  ├─ 我在设计产品 ──→ 用 pm-product-strategy
  │
  ├─ 我在写文档/PRD ──→ 用 pm-execution
  │
  ├─ 我在写代码 ──→ 用 test-driven-development
  │
  ├─ 我在修bug ──→ 用 systematic-debugging
  │
  ├─ 我在审查代码 ──→ 用 requesting-code-review
  │
  ├─ 我要上线了 ──→ 用 verification-before-completion
  │
  └─ 我在回忆过去 ──→ 用 agentmemory recall
```

---

## 🌲 二级决策：具体场景怎么选？

### 场景1：我有多个任务要并行做

**问：** 任务之间是否独立？
- ✅ 是 → `dispatching-parallel-agents`
- ❌ 否 → `subagent-driven-development`

### 场景2：我遇到一个复杂的bug

**问：** 你知道bug在哪吗？
- ✅ 知道大概位置 → `systematic-debugging`（系统化排查）
- ❌ 完全不知道 → 先用 `writing-plans` 写排查计划

### 场景3：我要开始一个新项目

**正确顺序：**
```
1. brainstorming → 找方向
2. pm-market-research → 验证市场
3. pm-product-strategy → 定策略
4. writing-plans → 写计划
5. pm-execution → 写PRD/OKR
6. using-git-worktrees → 隔离开发
7. test-driven-development → 写测试
8. subagent-driven-development → 执行开发
9. requesting-code-review → 代码审查
10. verification-before-completion → 上线前验证
11. finishing-a-development-branch → 合并
```

### 场景4：我要做市场推广

**问：** 产品处于什么阶段？
- 还没上线 → `pm-go-to-market`（GTM策略）
- 已上线需要增长 → `pm-marketing-growth`（增长策略）
- 需要数据驱动 → `pm-data-analytics`（数据分析）

### 场景5：我想提高开发效率

**问：** 瓶颈在哪？
- 重复性工作多 → `subagent-driven-development`
- 任务太分散 → `dispatching-parallel-agents`
- 代码质量差 → `test-driven-development` + `requesting-code-review`
- 调试浪费时间 → `systematic-debugging`
- 每次都要重新解释项目 → `agentmemory`
