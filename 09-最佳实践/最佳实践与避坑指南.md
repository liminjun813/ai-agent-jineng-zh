# AI Agent 最佳实践与避坑指南

> 从无数次试错中总结的经验教训，避免踩同样的坑。

---

## 🔥 高频踩坑Top 10

### 坑1：不写计划就开始干活
**症状：** 任务做一半发现方向错了，重来一遍。
**正确做法：** 任何超过3步的任务，先用 `writing-plans` 写计划。
**口诀：** 想清楚再做，做了再想是返工。

### 坑2：不写测试直接写代码
**症状：** 代码写完发现不符合预期，调试半天。
**正确做法：** 先用 `test-driven-development` 写测试，再写实现。
**口诀：** 先写测试，再写代码。

### 坑3：不隔离开发直接改main
**症状：** 改着改着把main搞坏了，其他人在用的分支也受影响。
**正确做法：** 新功能先用 `using-git-worktrees` 隔离。
**口诀：** 永远不要直接在main上改代码。

### 坑4：不验证就说是"完成了"
**症状：** 自以为完成了，上线才发现漏了关键功能。
**正确做法：** 上线前必须用 `verification-before-completion` 验证。
**口诀：** 没验证=没完成。

### 坑5：不审查就合并代码
**症状：** 合并后发现安全漏洞或逻辑错误。
**正确做法：** 合并前用 `requesting-code-review` 审查。
**口诀：** 自己的代码自己看不出来bug。

### 坑6：用grep思维排查bug
**症状：** 盲目改代码，改完问题还在。
**正确做法：** 用 `systematic-debugging` 四阶段法：理解→分析→假设→验证。
**口诀：** 先理解bug，再动手改。

### 坑7：串行处理独立任务
**症状：** 明明可以并行的任务，一个一个做，浪费大量时间。
**正确做法：** 独立任务用 `dispatching-parallel-agents` 并行处理。
**口诀：** 独立任务，并行处理。

### 坑8：每次新会话重新解释一切
**症状：** 每次对话都要重新说"我是谁、项目在做什么"。
**正确做法：** 用 `agentmemory` 自动捕获和检索上下文。
**口诀：** 让记忆替你说话。

### 坑9：不区分"能不能做"和"怎么做"
**症状：** 直接开始执行，发现第一步就走不通。
**正确做法：** 先问"能不能干"，再动手。
**口诀：** 先问能不能干，再动手怎么做。

### 坑10：连续失败≥3次还不换策略
**症状：** 同一个方法试了3次都不行，还硬试第4次。
**正确做法：** 连续失败≥3次→停止→推人工确认。
**口诀：** 三次不成就停手，换人或换方法。

## ✅ 最佳实践清单

### 开发流程最佳实践

#### 1. 任务开始前
- [ ] 多步任务 → 先用 `writing-plans`
- [ ] 新功能 → 先用 `using-git-worktrees` 隔离
- [ ] 新功能 → 先用 `test-driven-development` 写测试

#### 2. 开发过程中
- [ ] 独立任务 → 用 `dispatching-parallel-agents`
- [ ] 批量任务 → 用 `subagent-driven-development`
- [ ] 遇到bug → 用 `systematic-debugging`

#### 3. 代码完成后
- [ ] 合并前 → 用 `requesting-code-review`
- [ ] 上线前 → 用 `verification-before-completion`

#### 4. 项目收尾
- [ ] 合并 → 用 `finishing-a-development-branch`
- [ ] 经验沉淀 → 用 `writing-skills` 创建技能
- [ ] 上下文保存 → 用 `agentmemory remember`

### 产品流程最佳实践

#### 1. 创意阶段
- [ ] 找方向 → `brainstorming`
- [ ] 验证市场 → `pm-market-research`
- [ ] 设计策略 → `pm-product-strategy`

#### 2. 产品阶段
- [ ] 识别假设 → `pm-product-discovery`
- [ ] 写PRD → `pm-execution`
- [ ] 定OKR → `pm-execution`

#### 3. 上市阶段
- [ ] 上市计划 → `pm-go-to-market`
- [ ] 增长策略 → `pm-marketing-growth`
- [ ] 数据分析 → `pm-data-analytics`

### 记忆管理最佳实践

#### 1. 自动记忆
- AgentMemory自动捕获所有操作
- 无需手动干预

#### 2. 手动保存关键信息
- 用户偏好 → 立即 `remember`
- 重要决策 → 立即 `remember`
- 踩过的坑 → 立即 `remember`

#### 3. 定期回顾
- `session-history` 查看最近会话
- `recap` 回顾近期工作
- 清理过期记忆 → `forget`

## 💡 进阶技巧

### 1. 技能组合拳

**组合1：快速迭代**
```
writing-plans → subagent-driven-development → verification-before-completion
```
适用于：快速开发小功能

**组合2：高质量交付**
```
writing-plans → test-driven-development → subagent-driven-development → requesting-code-review → verification-before-completion
```
适用于：核心功能开发

**组合3：大规模重构**
```
using-git-worktrees → writing-plans → subagent-driven-development → requesting-code-review → finishing-a-development-branch
```
适用于：大规模代码重构

### 2. 跨Agent协作

当任务超出单个Agent能力时：
```
dispatching-parallel-agents
→ 分配独立任务给不同Agent
→ 各自执行
→ 汇总结果
```

### 3. 持续改进

```
每次项目结束后：
1. recap → 回顾做了什么
2. writing-skills → 沉淀为新技能
3. agentmemory remember → 保存经验教训
```
