## 🚀 技巧1：技能链式调用

单个技能有用，但**技能链**威力更大。

### 链式1：完整功能开发
```
writing-plans（写计划）
  → using-git-worktrees（隔离开发）
  → test-driven-development（先写测试）
  → subagent-driven-development（执行开发）
  → requesting-code-review（代码审查）
  → verification-before-completion（上线验证）
  → finishing-a-development-branch（合并分支）
```
**效果：** 从想法到上线，全程自动化，零手动失误。

### 链式2：产品从0到1
```
brainstorming（头脑风暴）
  → pm-market-research（市场研究）
  → pm-product-strategy（产品策略）
  → writing-plans（实施计划）
  → pm-execution（PRD+OKR+Sprint）
  → pm-go-to-market（上市计划）
  → pm-marketing-growth（营销策略）
  → pm-data-analytics（数据分析）
```
**效果：** 完整的创业流程，从想法到数据驱动。

### 链式3：快速修复
```
systematic-debugging（系统化调试）
  → writing-plans（修复计划）
  → test-driven-development（回归测试）
  → subagent-driven-development（执行修复）
  → verification-before-completion（验证修复）
```
**效果：** 不盲目改代码，每次修复都有据可依。

## 🚀 技巧2：并行加速

### 场景：6个独立测试失败

**低效做法：** 一个一个修，6个任务 × 10分钟 = 60分钟

**高效做法：**
```
dispatching-parallel-agents
  → Agent 1: 修测试A + 测试B
  → Agent 2: 修测试C + 测试D
  → Agent 3: 修测试E + 测试F
```
**效果：** 60分钟 → 20分钟，提速3倍。

### 场景：同时做多个功能

```
subagent-driven-development
  → 任务1: 用户登录模块
  → 任务2: 商品搜索模块
  → 任务3: 订单管理模块
  → 任务4: 支付集成模块
  → 任务5: 通知系统模块
  → 任务6: 数据分析模块
```
每个任务由独立Agent执行，互不干扰。

## 🚀 技巧3：记忆增强

### 技巧3a：主动记忆关键决策

```
# 每次重要决策后
"记住这个：我们选择了方案A而不是方案B，
原因是成本更低，虽然扩展性稍差。"

# AgentMemory会自动记录
# 下次会话自动加载相关上下文
```

### 技巧3b：经验沉淀

```
# 解决一个难题后
"记住这个：微信解密工具在macOS上需要
先给文件加执行权限，否则报permission denied。"

# 下次遇到类似问题，Agent自动检索
# 节省重新排查的时间
```

### 技巧3c：会话回顾

```
# 查看上周做了什么
recap "this week"

# 查看上次会话
handoff

# 查看特定会话历史
session-history
```

## 🚀 技巧4：安全加固

### 技巧4a：多层安全审查

```
# 第一层：代码审查
requesting-code-review

# 第二层：AI代码审计
pm-ai-shipping

# 第三层：完工验证
verification-before-completion
```

### 技巧4b：敏感信息保护

```
# 在代码中
# ❌ 错误：硬编码密码
password = "admin123"

# ✅ 正确：从环境变量读取
import os
password = os.environ.get("DB_PASSWORD")

# 记住这个最佳实践
"记住：所有敏感信息必须从环境变量读取，
禁止硬编码。"
```

## 🚀 技巧5：性能优化

### 技巧5a：批量处理

```
# 低效：逐条处理1000条数据
for item in data:
    process(item)

# 高效：批量处理
subagent-driven-development
  → 任务1: 处理数据1-200
  → 任务2: 处理数据201-400
  → 任务3: 处理数据401-600
  → 任务4: 处理数据601-800
  → 任务5: 处理数据801-1000
```

### 技巧5b：缓存策略

```
# 记住：频繁查询的数据应该缓存
"记住：用户偏好数据变化频率低，
查询结果应缓存24小时。"
```

## 🚀 技巧6：团队协作

### 技巧6a：跨Agent分工

```
# 大型项目分工
dispatching-parallel-agents
  → Agent A（前端）: UI组件开发
  → Agent B（后端）: API接口开发
  → Agent C（数据）: 数据库设计
  → Agent D（测试）: 测试用例编写
  → Agent E（文档）: API文档编写
```

### 技巧6b：代码一致性

```
# 统一代码风格
# 在writing-plans中指定：
- 缩进：4空格
- 命名：camelCase
- 注释：JSDoc格式
- 测试：pytest
```
