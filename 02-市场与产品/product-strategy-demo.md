# 案例：产品策略 — 「智选AI」的商业模式

## 背景

市场研究完成后，需要制定产品策略。

## 使用pm-product-strategy技能

```
基于市场研究结果，请帮我制定「智选AI」的产品策略，包含：
1. 商业画布（Business Model Canvas）
2. 价值主张
3. SWOT分析
4. 定价策略
```

### 1. business-model — 商业画布
```
请生成完整的9格商业画布：
- 客户细分
- 价值主张
- 渠道通路
- 客户关系
- 收入来源
- 核心资源
- 核心业务
- 关键合作
- 成本结构
```

### 2. value-proposition — 价值主张
使用JTBD（Jobs To Be Done）框架：
```
价值主张模板：
- 当[宝妈在购物时]
- 她们想要[快速找到最划算的正品]
- 以便[省下钱给家人买更多好东西]
- 替代方案[自己手动比价、看评价]
```

### 3. swot-analysis — SWOT分析
```
请分析「智选AI」的：
- 优势(S)：AI技术、精准推荐、低获客成本
- 劣势(W)：新品牌、数据积累少、技术门槛
- 机会(O)：下沉市场电商增长、AI技术成熟、短视频带货兴起
- 威胁(T)：巨头竞争、监管风险、用户信任建立难
```

### 4. pricing-strategy — 定价策略
```
请分析以下定价模式：
- 免费+广告（CPC分成）
- 会员制（月费/年费）
- 佣金分成（每笔订单抽成）
- 混合模式
输出：每种模式的收入预测、优缺点、推荐方案
```

## 关键要点

- pm-product-strategy确保策略分析**结构化、有框架**
- 每个工具都有**标准模板**，输出可直接用于商业计划书
- 适用于：**新产品定位、商业模式设计、战略规划**
