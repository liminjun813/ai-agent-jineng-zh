# 案例：GTM策略 — 「智选AI」上市计划

## 背景

产品验证通过后，需要制定上市策略。

## 使用pm-go-to-market技能

### 1. gtm-strategy — 上市策略
```
请制定「智选AI」的GTM策略：
- 目标市场：三四线城市宝妈
- 核心功能：AI推荐 + 比价 + 优惠券
- 上市时间：MVP后3个月内
- 目标：获取10万用户
```

输出包含：
```
1. Beachhead Segment（海滩头市场）：XX线城市宝妈
2. ICP（理想客户画像）
3. 信息传递策略：「AI帮你省钱，一省就是XX元」
4. 渠道策略：
   - 微信社群裂变
   - 抖音/KOL合作
   - 地推（母婴店合作）
5. 成功指标
6. 上市时间表
```

### 2. growth-loops — 增长飞轮
```
请为「智选AI」设计增长飞轮：
核心：用户推荐 → 新用户 → 更多数据 → 更好推荐
```

输出：
```
飞轮1：推荐裂变
- 用户每次省钱后分享到微信群
- 朋友点击链接注册
- 新用户的消费数据丰富推荐模型
- 推荐更准 → 老用户更满意 → 更愿意分享

飞轮2：内容生态
- 用户晒单 → 产生内容
- 内容吸引新用户
- 新用户产生更多内容
```

### 3. competitive-battlecard — 竞争战卡
```
请为销售团队创建竞争战卡：
- 对比竞品：淘宝/拼多多/抖音
- 我们的优势话术
- 常见客户异议处理
- 赢单策略
```

## 关键要点

- GTM策略确保**产品上线不是终点，而是起点**
- 增长飞轮设计让增长**可持续、可自动化**
- 竞争战卡让**一线销售有武器**
