# 案例：市场研究 — 三四线城市宝妈电商市场

## 背景

确定目标用户后，需要深入了解市场。

## 使用pm-market-research技能

打开Hermes Agent，加载 `pm-skills:pm-market-research` 技能，输入：

```
请帮我分析「智选AI」的目标市场：
- 目标用户：三四线城市25-40岁女性（宝妈为主）
- 需要：
  1. 用户画像（至少3个细分群体）
  2. 竞品分析（淘宝、拼多多、京东、抖音电商）
  3. 市场细分
  4. 用户情绪分析（从应用商店评论提取）
```

## 子技能详解

### user-personas — 用户画像
```
请基于以下特征创建用户画像：
- 城市级别：三线及以下城市
- 年龄：25-40岁
- 身份：宝妈
- 消费习惯：价格敏感、信任熟人推荐
- 痛点：没时间比价、担心买到假货
```

输出格式：
```
用户画像：「精打细算的张姐」
- 基本信息：32岁，三线城市，有一个4岁孩子
- 消费场景：每周网购1-2次，主要在拼多多和淘宝
- 核心痛点：1) 不会用复杂优惠券 2) 经常买贵了 3) 怕买到假货
- 期望：希望有个AI帮她比价、推荐划算的正品
- 获取渠道：微信群分享、朋友推荐
```

### competitor-analysis — 竞品分析
```
请分析5个竞品：
1. 淘宝 — 优势：品类全；劣势：推荐太复杂
2. 拼多多 — 优势：价格低；劣势：质量参差不齐
3. 京东 — 优势：品质好；劣势：下沉市场覆盖弱
4. 抖音电商 — 优势：内容推荐；劣势：冲动消费多
5. 小红书 — 优势：种草效果好；劣势：价格偏高
```

### market-segments — 市场细分
```
请细分市场，每个市场包含：
- 市场规模（TAM/SAM/SOM）
- 用户特征
- 增长趋势
- 竞争强度
```

### sentiment-analysis — 情绪分析
```
分析以下用户评论的情绪分布：
（粘贴应用商店评论文本）
输出：正面/负面/中性比例 + 关键词提取
```

## 关键要点

- pm-market-research的每个子技能都有**结构化输出模板**
- 不是让AI"随便写写"，而是按框架分析
- 适用于：**进入新市场、竞品调研、用户研究**
