# 实战案例：从0到1创建「鑫选优品」手机配件电商

> 基于真实项目「鑫源光电」的真实业务模式，用23个Hermes Agent技能完整走一遍创业流程

---

## 项目背景

**公司：** 鑫选优品（化名，基于真实案例改编）
**业务：** iPhone配件批发 + 零售
**地址：** 西安东35号
**负责人：** 一条龙手机配件鑫源光电
**目标：** 6个月内搭建AI驱动的电商推荐系统，12个月实现线上盈利

---

## Phase 1: 创意发想

### 1.1 头脑风暴

**场景：** 老板说"现在同行太多，我们需要差异化"。

**操作：** 使用 `brainstorming` 技能

```
请帮我头脑风暴：
鑫源光电在西安东35号做iPhone配件批发，
主要客户是三四线城市的手机维修店和小零售商。
怎么做出差异化？

请用brainstorming技能输出10个差异化方向，
每个方向包含：名称、目标客户、核心优势、潜在风险
```

**产出（示例）：**
1. **AI智能配货** — 根据客户历史采购数据推荐最优组合
2. **闪电发货** — 西安周边24小时达
3. **配件+教程捆绑** — 卖手机壳送安装视频
4. **会员积分制** — 采购越多折扣越高
5. ...

### 1.2 写实施计划

**操作：** 使用 `writing-plans` 技能

```
请用writing-plans技能帮我制定一个6个月MVP实施计划，
目标是搭建一个AI推荐系统，
主要功能：客户历史采购分析、智能配货建议、库存预警。
每个阶段包含：目标、关键任务、验收标准、时间线。
```

**产出：** 6个月分阶段计划（详见 `01-创意发想/writing-plans-demo.md`）

## Phase 2: 市场与产品

### 2.1 市场研究

**场景：** 需要知道目标市场有多大、竞争对手是谁。

**操作：** 使用 `pm-market-research` 技能

```
请用pm-market-research分析：
目标市场：中国三四线城市手机维修店和配件零售商
产品：iPhone 15/16系列配件（壳、膜、充电线、充电头）
需要输出：
1. 目标用户画像（至少3类）
2. 竞品分析（至少5家）
3. 市场细分
4. 用户情绪分析
```

**产出：** 用户画像、竞品分析矩阵（详见 `02-市场与产品/market-research-demo.md`）

### 2.2 产品策略

**场景：** 确定商业模式和价值主张。

**操作：** 使用 `pm-product-strategy` 技能

```
请用pm-product-strategy制定「鑫选优品」产品策略：
核心业务：iPhone配件批发
差异化方向：AI智能配货
需要输出：
1. 商业模式画布
2. 价值主张
3. SWOT分析
4. 定价策略
```

**产出：** 商业模式、价值主张、SWOT（详见 `02-市场与产品/product-strategy-demo.md`）

### 2.3 GTM上市策略

**场景：** 确定怎么把产品推出去。

**操作：** 使用 `pm-go-to-market` 技能

```

目标客户：西安周边100公里内的手机维修店
核心功能：AI智能配货
需要输出：
1. 海滩头市场分析
2. ICP（理想客户画像）

4. 增长飞轮设计
```

**产出：** 上市计划、增长飞轮（详见 `02-市场与产品/gtm-strategy-demo.md`）

## 关键经验

### 1. 技能有执行顺序
不是所有技能都可以乱序使用。比如：
- 先 `brainstorming` 找方向，再 `writing-plans` 做计划
- 先 `writing-plans` 写计划，再 `subagent-driven-development` 执行
- 先 `test-driven-development` 写测试，再 `verification-before-completion` 验证

### 2. 技能之间有依赖
- `pm-market-research` 的产出是 `pm-product-strategy` 的输入
- `pm-execution` 的PRD是开发团队的工作依据
- `subagent-driven-development` 需要 `writing-plans` 的输出

### 3. 记忆系统很重要
用 `agentmemory` 记住每次决策的背景，避免重复讨论。

### 4. 模板拿来即用
项目中的 `templates/` 目录提供4个可直接复用的模板，
替换方括号内容即可使用。
